## 📌 Featured Project

### 🛒 Event-Driven Order Management Platform

An **enterprise-style**, **event-driven microservices backend** implementing real-world distributed system patterns.
> Java • Spring Boot • Apache Kafka • Spring Security (JWT) • Spring Cloud Gateway • MySQL

**🎯 Key Highlights:**
- Designed **event-driven microservices** using Spring Boot and Kafka for asynchronous, decoupled domain processing
- Applied **Factory and Strategy design patterns** to dynamically switch payment and notification routes
- Secured the API edge with **Spring Cloud Gateway** using JWT authentication and role-based authorization (RBAC)
- Built resilience with **Kafka retry topics and Dead Letter Queues (DLQ)**
- Followed **SOLID principles and Low-Level Design (LLD)** throughout

[![View Repository](https://img.shields.io/badge/View%20Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/KarriJayakrishna/Event-Driven-Order-Management-Platform)
